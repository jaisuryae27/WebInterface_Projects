## Project Description
A responsive personal Hobbies Page built using React that showcases a collection of hobbies with icons, descriptions, and a highlighted featured hobby ("Listening to Music"). Designed with dark-themed aesthetics, glowing gradients, animated dashed rings, Google Fonts (Sora & Manrope), and CSS Grid.

## Concepts Implemented
- React & JSX
- Component-Based Architecture (`Header`, `FeaturedHobby`, `HobbyBadge`, `HobbyCard`, `HobbyGrid`, `Footer`)
- Props passing
- Array methods (`find()`, `filter()`, `map()`)
- CSS Grid & Flexbox responsive layouts
- CSS Custom Properties (Variables)
- CSS Animations (`@keyframes spin` with `prefers-reduced-motion` support)
- Google Fonts integration (Sora and Manrope)

## How to Run the Project

1. Open a terminal inside this directory (`D:\projects wi\hobbies`).
2. If `node_modules` is not already installed, run:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm start
   ```
   *(or `npm run dev`)*
4. Open the displayed URL (typically `http://localhost:3000`) in your browser.
