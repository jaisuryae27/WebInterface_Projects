## Project Description
A Student Dashboard Application built with React that displays student details, subjects, attendance, and placement eligibility with component structure, props passing, and conditional rendering.

## Concepts Implemented
- React & JSX
- Component-Based Architecture (`Header`, `StudentCard`, `SubjectList`, `Footer`)
- Props passing
- Arrays & Array mapping (`map()`)
- Conditional Rendering (Ternary operators for attendance and placement eligibility)
- Inline Styling & External CSS

## How to Run the Project

1. Open a terminal inside this directory (`D:\projects wi\school_dashboard`).
2. If `node_modules` is not already installed, run:
   ```bash
   npm install
   ```
3. Start the application:
   ```bash
   npm start
   ```
   *(or `npm run dev`)*
4. Open the displayed URL (typically `http://localhost:3000`) in your browser.
