## Project Description
A personal portfolio web application developed using React, React Router, and CSS. The portfolio showcases personal information, technical skills, projects, and contact details through multi-page client-side navigation.

## Pages & Routes Implemented
- `/` (`Home.jsx`): Hero intro greeting ("Hello, I'm Shakthi"), student title ("AI & Data Science Student"), and introduction.
- `/about` (`About.jsx`): About Me summary and technical skill tags (HTML, CSS, JavaScript, React, Java, Python).
- `/projects` (`Projects.jsx`): Responsive project cards displaying:
  - **College Website**: Responsive website built using HTML, CSS, and JavaScript.
  - **Portfolio Website**: Personal portfolio built with React, React Router, and CSS.
  - **Titanic EDA**: Data analysis and exploratory data project using Python, Pandas, and Matplotlib.
- `/contact` (`Contact.jsx`): Direct contact details (Email, Phone, Location).

## Styling & Responsive Layout
- Dark navbar with hover color transitions on navigation links.
- Gradient background for hero sections.
- Boxed card layout (`.content-box`, `.project-card`).
- Responsive CSS Grid and Flexbox with `@media (max-width: 768px)` breakpoints.

## How to Run the Project

1. Open a terminal in `D:\projects wi\portfolio`.
2. If dependencies are not already installed, run:
   ```bash
   npm install
   ```
3. Start the application:
   ```bash
   npm start
   ```
   *(or `npm run dev`)*
4. Open `http://localhost:3000` in your browser.
